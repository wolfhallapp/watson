# The Oracle's knowledge folder

Anything you put in this folder, the Oracle knows. You can add files here on the PC or on
GitHub (Add file → Create new file, inside `knowledge/`). The Oracle pulls from GitHub each
time it starts, and it notices new or changed files before your next request.

- Markdown (`.md`) or plain text works best. One topic per file, with a clear name, like
  `family-schedule.md`, `car-info.md` or `how-i-like-emails.md`.
- Short text files go straight into what the Oracle knows. Big files, PDFs and pictures are
  listed by name, and the Oracle opens them when they're relevant.
- **This folder is pushed to GitHub. Don't put passwords, card numbers or account logins here.**
- You can also just say "The Oracle, add this to your knowledge: …" and it writes the file for you.
